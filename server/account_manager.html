Important Notes:

No Refunds or Item Exchanges

Once you choose an item, there are no refunds, exchanges, or repicks. Confirm the exact item name and ID before redeeming.

Class Items

Class items are granted with their class points at maximum level.

Redeeming the item does not grant associated badges, quest completion, achievements, or other progression.

Newly Added Items

Only items already present in this server's catalog are available.

Other Limitations

  • Redemption adds the item to inventory; relog if the game is already open.
  • Staff-only or personalized items should be excluded administratively before public launch.
